Dynamic Workers Demo - Embedded Widget Example

Embedded Widget

The widget below is embedded via an iframe tag. It demonstrates that the widget can be safely embedded in other pages.

Verification Checklist

Verify iframe Embedding

  1. The widget should render above in an iframe (no framing errors)
  2. The example dropdown should be populated
  3. Click an example and confirm the code appears
  4. Click a suggested URL chip and confirm it fills the URL field
  5. Click "Run" and confirm results appear

Verify HTML/Script Escaping (AC6.1)

  1. In the iframe, switch to "Custom Code" mode
  2. Paste this code: 
    export default () => ({
  html: '<script>alert("XSS")</script>'
})
  3. Click "Run"
  4. Confirm the result shows the text literally, not executing the script
  5. No alerts should appear
  6. The HTML/script should appear as escaped text in the results pane
If the iframe fails to load or shows errors, check:
  • The worker is running locally (npm run dev)
  • Static assets are being served from public/
  • No X-Frame-Options: DENY headers are blocking iframe embedding
